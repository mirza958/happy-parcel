# Where the app is hosted

I use [Vercel](https://happy-parcel.vercel.app/) for the live app and keep the source on [GitHub](https://github.com/mirza958/happy-parcel). The storefront shown in my screenshots comes from source commit [6b0946b](https://github.com/mirza958/happy-parcel/commit/6b0946b8429703866c5c04883fd44a99fcb996e8). Later documentation updates include the refreshed screenshots.

Vite builds the app into `dist`. I use the rewrite in `vercel.json` so a direct visit to a React route such as `/box` opens the app.
