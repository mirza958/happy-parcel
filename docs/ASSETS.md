# Product visuals

The twelve product images in `public/images/products/` are original AI-generated photorealistic images made for this fictional student business. They do not represent photographs of real stock and are not copied from BOXFOX. Their coordinated ivory backgrounds and studio lighting provide a consistent catalogue style. The original generated sheet was cropped into twelve square images and exported as WebP to keep downloads small.

Each image filename matches the product's stable ID. ProductPhoto supplies alternative text, lazy loading for catalogue thumbnails, eager loading for details, explicit dimensions, and an illustration fallback if an image fails. The SVG hero and packing preview remain original illustrations.
